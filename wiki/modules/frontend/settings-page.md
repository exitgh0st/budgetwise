# Settings Page

## Purpose

Manage profile/security actions, user preferences, export, usage limits, and permanent account deletion.

## Key UI

- Currency selection
- Email reminder toggle, mode, and digest-hour controls
- Change-email and change-password dialogs
- JSON export download
- Usage card with per-resource progress bars
- Danger zone with typed-confirmation account deletion
