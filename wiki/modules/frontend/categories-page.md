# Categories Page

## Purpose

Manage user categories while showing system categories as read-only context.

## Key UI

- Sortable desktop table and mobile list
- System badge with edit/delete disabled
- FK-protected delete errors surfaced through snackbars
- Near-limit warning chip and disabled add button at the usage cap
