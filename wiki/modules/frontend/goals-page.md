# Goals Page

## Purpose

Manage savings and debt-payoff goals plus linked contribution transactions.

## Key UI

- Goal cards with progress, target date, and contribution count
- Goal-type picker before opening the main goal form
- Searchable account and category selects in dialogs
- Expandable linked-transactions table with edit/delete actions
- Near-limit warning chip and disabled add button at the usage cap
