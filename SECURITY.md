# Security

## Current Handling

- Keep `.env` and `.env.production` out of git.
- Keep `budgetwise-ui/src/environments/environment.prod.ts` out of git.
- Commit only placeholder values in tracked frontend environment templates.
- Supply real production values through deployment environment variables before building the Angular app.

## Secret Rotation Checklist

Rotate these values in their source systems whenever exposure is suspected:

1. `DEEPSEEK_API_KEY`
2. `DATABASE_URL` password / full connection string
3. `SUPABASE_ANON_KEY`
4. `SUPABASE_SERVICE_ROLE_KEY`
5. `INTERNAL_ADMIN_SECRET`

Also verify Supabase RLS remains enabled after any rotation work.

## Frontend Production Env

`budgetwise-ui/src/environments/environment.prod.ts` is generated by `budgetwise-ui/scripts/prepare-prod-environment.mjs` during `npm run build`.

Set these environment variables in Render before the frontend build runs:

- `BUDGETWISE_API_URL`
- `SUPABASE_URL`
- `SUPABASE_ANON_KEY`

If they are missing, the script falls back to the placeholder template so local builds still succeed without exposing secrets.

## Git History Cleanup

If credentials were committed, rotate them first, then scrub history before pushing the cleaned branch.

Preferred approaches:

1. `git filter-repo` if available
2. BFG Repo-Cleaner for simple file or text removal

Example BFG flow:

```bash
git clone --mirror <repo-url> budgetwise-mirror
cd budgetwise-mirror
java -jar bfg.jar --delete-files .env
java -jar bfg.jar --delete-files .env.production
java -jar bfg.jar --delete-files environment.ts
java -jar bfg.jar --delete-files environment.prod.ts
git reflog expire --expire=now --all
git gc --prune=now --aggressive
git push --force --all
git push --force --tags
```

After a history rewrite, every collaborator should re-clone or hard-reset to the rewritten remote.

## Deployment Update Checklist

1. Rotate exposed credentials in DeepSeek, database hosting, Supabase, and Render.
2. Update Render backend env vars with the rotated values.
3. Update Render frontend build env vars with `BUDGETWISE_API_URL`, `SUPABASE_URL`, and `SUPABASE_ANON_KEY`.
4. Trigger a fresh deploy.
5. Smoke test login, onboarding, transaction create, and chat.

## Verification

Run these checks after changes:

```bash
cd budgetwise-ui && npm run build
cd budgetwise-api && npm run build
cd budgetwise-api && npm run lint
```
